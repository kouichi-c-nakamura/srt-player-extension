# Privacy Policy for Manual Sync SRT Subtitles Player

Last updated: November 2026

Manual Sync SRT Subtitles Player ("the Extension") is committed to protecting your privacy. This Privacy Policy explains our data practices.

## 1. No Collection of Personal Data
The Extension does not collect, transmit, distribute, sell, or store any personal data or personally identifiable information (PII).

## 2. Local Data Storage
The Extension stores data exclusively on your local device using the browser's local storage API (`chrome.storage.local` / `browser.storage.local`):
- Loaded subtitle files (.srt text)
- Playback timeline progress (elapsed timestamp)
- Appearance preferences (font family, font size, subtitle color)
- Site whitelist configurations

This data remains entirely on your local machine and is never transmitted to any external server or third party.

## 3. Host Permissions and Web Activity
The Extension requests access to web pages solely to display the floating subtitle overlay and user interface on video streaming platforms. The Extension runs an internal whitelist check and only executes its script on websites explicitly permitted by the user. It does not monitor, inspect, log, or transmit your browsing history or web page contents.

## 4. Third-Party Services
The Extension does not use any third-party analytics, tracking services, or external advertising networks.

## 5. Contact
If you have any questions or feedback regarding this Privacy Policy, please open an issue in this repository.
